Tentang WebGIS

WebGIS ini menampilkan seluruh data spasial analisis dasar wilayah untuk penyusunan Rencana Detail Tata Ruang (RDTR) Kecamatan Sawoo, Kabupaten Ponorogo. Data bersumber dari berkas shapefile/raster yang tersimpan pada repositori ini dan telah diproyeksikan ke WGS 84 (EPSG:4326).

  • Aktifkan layer pada panel kiri; klik objek di peta untuk melihat atributnya.
  • Gunakan tombol Aa pada layer tertentu untuk menampilkan label objek.
  • Geser penggeser opasitas pada setiap layer aktif untuk mengatur transparansi.
  • Basemap Google Satelit/Hibrida/Jalan/Medan tersedia pada pemilih basemap di kanan bawah.

Basemap © Google, OpenStreetMap contributors, CARTO. Geometri disederhanakan untuk keperluan penayangan web; gunakan berkas asli (ZIP) untuk analisis presisi.
